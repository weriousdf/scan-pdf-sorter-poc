# 모델 선정 근거

확인 날짜: **2026-09-24**

---

## 1. 무엇을 판단해야 하는가

| 판단 | 방법 | AI 필요 |
|---|---|---|
| 가로 / 세로 | 페이지 가로·세로 길이 비교 | 아니오 |
| 페이지 자체가 A4 보다 작은가 (A5 등) | 페이지 크기를 A4 의 95% 와 비교 | 아니오 |
| **A4 페이지 위에 작은 종이가 놓여 있는가** | 이미지를 보고 판단 | **예** |

앞의 두 가지는 모든 방식에 공통으로 규칙을 쓰고, 세 번째만 후보끼리 비교한다.

## 2. 조건으로 먼저 걸러낸 것

**조건: 고객 서류를 외부로 보내지 않는다.** 그래서 GPT-4o·Gemini 같은 외부 API 로 이미지를 보내
물어보는 방법은 정확도와 상관없이 제외했다. 아마 가장 정확했을 후보지만 쓸 수 없다.

## 3. 후보

| | **기준선: 규칙** | **CLIP 제로샷 분류** | (검토 후 제외) SAM | (검토 후 제외) YOLO |
|---|---|---|---|---|
| 방식 | 잉크(어두운 픽셀)가 있는 영역의 가로·세로 비율 | 이미지와 설명문의 유사도 | 영역 분할 | 물체 탐지 |
| 학습 필요 | 없음 | **없음** (설명문만 작성) | 없음 | 여권·신분증 학습 데이터 필요 |
| 실행 위치 | 로컬 | 로컬 (CPU 로도 충분) | 로컬 | 로컬 |
| 모델 크기 | — | 약 600MB | 375MB~2.4GB | 수십 MB |

### 기준선을 규칙으로 둔 이유

"95% 이상이면 A4" 는 사용자가 직접 정한 판정 기준이다. 이것을 가장 단순하게 코드로 옮기면 "어두운 픽셀이 있는
영역이 페이지의 95% 이상인가" 가 된다. 사람이 떠올릴 수 있는 첫 번째 자동화 방법이라 기준선으로 삼았다.
흰 종이·흰 스캐너에서는 **종이 경계가 보이지 않아** 종이 크기를 잴 수 없다는 한계가 처음부터 예상됐다.
실제 서류에서 가장자리 검출(Canny)로 종이 경계를 찾는 방법도 시도했지만, 경계가 거의 잡히지 않아 쓰지 않았다.

### CLIP 을 고른 이유

- **학습 데이터가 필요 없다.** 이 문제의 "작은 서류" 예시는 실제 서류 26쪽 중 2장뿐이라, 탐지 모델을 학습시킬
  데이터가 없다. CLIP 은 "빈 종이 위에 놓인 작은 여권" 같은 **문장만으로** 분류할 수 있다(제로샷).
- **"페이지 전체의 모습"을 판단한다.** 필요한 것은 물체 하나의 위치가 아니라 "종이 한 장이 꽉 찬 페이지인가,
  빈 종이 위에 작은 것이 놓인 페이지인가" 라는 전체 인상이다. 이미지 전체를 한 번에 보는 CLIP 이 이 질문에 맞다.
- **CPU 로도 빠르다.** 판단은 72dpi 저해상도 이미지로 충분하고, 26쪽 판정이 몇 초 안에 끝난다.
- `openai/clip-vit-base-patch32` 를 골랐다. 더 큰 모델(ViT-L)은 정확도가 오를 수 있지만, 이 PoC 의 질문은
  "모델을 키우면 좋아지는가" 가 아니라 "이 자리에 이미지 이해 모델이 필요한가" 이다.

### SAM · YOLO 를 쓰지 않은 이유

- **SAM** 은 어디를 딸지 점이나 상자로 지목해야 한다. 흰 종이 위 흰 종이는 경계가 약해서, 분할 결과가
  종이가 아니라 글자 덩어리·표·도장을 따로따로 잡을 가능성이 크다. 결과 마스크를 다시 "종이인가" 판정하는
  규칙이 필요해져 규칙 기준선의 문제로 돌아간다.
- **YOLO** 는 여권·신분증을 탐지하도록 학습시켜야 한다. 학습 데이터가 없고, 작은 아포스티유처럼
  "서류처럼 생긴 작은 종이"는 기존 클래스에 없다. Ultralytics YOLO 는 AGPL 라이선스라는 점도 있다.

## 4. 설명문(프롬프트) 두 가지 버전

CLIP 은 설명문에 따라 결과가 달라진다. 과적합을 막기 위해 순서를 정했다.

- **v1** — 결과를 보기 전에 작성. A4 설명 3개, 작은 서류 설명 3개 (주로 여권·신분증)
- **v2** — v1 이 **가짜 샘플에서** 틀린 2건(작은 아포스티유, 작은 확인서)만 보고 설명 3개를 추가.
  실제 서류 결과는 보지 않고 확정한 뒤, 실제 서류에 **한 번만** 돌렸다. 이후 더 고치지 않았다.

설명문 전문은 [`poc/split_pdf.py`](../poc/split_pdf.py) 의 `PROMPTS` 에 있다.
