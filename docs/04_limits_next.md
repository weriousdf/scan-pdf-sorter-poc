# 한계와 다음 단계

---

## 1. 이 PoC 의 한계

### 자료가 적다

- 실제 서류 26쪽 중 AI 가 판단해야 하는 작은 서류는 **1장**(A4 위 아포스티유)뿐이다. A5 페이지는 규칙으로 잡힌다.
  실제 서류의 96.2% 는 "전부 A4" 라고만 해도 나오는 25/26 과 맞힌 수가 같다. 차이는 틀린 쪽이 어디냐다.
- 여권·신분증 페이지는 **가짜 샘플에만** 있다. 실제 여권 스캔(홀로그램, 반사, 비닐 커버)에서 같은 결과가 나올지는
  확인하지 못했다.

### 설명문을 바꾸면 한쪽을 고치고 다른 쪽이 깨진다

v1 은 "서류처럼 생긴 작은 종이"를 놓쳤고, 그것을 고친 v2 는 "회색 배경 위 장식 테두리 졸업장"을 작은 서류로
보낸다. 제로샷 분류는 설명문이라는 가는 손잡이 하나로 조정하는 방식이라, 서로 닮은 두 모습을 동시에 가르기 어렵다.

### 판정 점수가 기준 가까이에 몰려 있다

v2 에서 작은 아포스티유는 0.580, 가장 높은 A4 서류(졸업장 제외)는 0.451 이다. 기준 0.5 와의 거리가 좁아서,
스캔 상태가 조금만 달라져도 판정이 뒤집힐 수 있다.

### 시간 이득은 크지 않다

수작업이 이미 14쪽에 2분으로 빠르다. 도구는 16초지만, 틀린 1장을 찾아 옮기는 검수 시간을 더하면
PDF 하나당 1분 남짓의 이득이다.

## 2. 실패 유형별 대응

| 실패 유형 | 사례 | 대응 |
|---|---|---|
| 서류처럼 생긴 작은 종이 → A4 | v1: 작은 아포스티유·확인서 | v2 설명문으로 해결 |
| 회색 배경 위 장식 테두리 졸업장 → 작은 서류 | v2: 가로 졸업장 원본 | 아래 두 가지 |
| 내용이 위쪽뿐인 A4 서류 → 작은 서류 | v1: 증명서 뒷장 | v2 설명문으로 해결 |

회색 배경 졸업장에 대한 대응 후보:

1. **규칙과 섞기** — 회색 배경 사진은 페이지 평균 밝기가 낮다(실제 서류 약 190, 흰 스캔 약 245).
   "흰 배경이 아닌 페이지는 A4" 규칙을 CLIP 앞에 두면 이 유형을 막을 수 있다. 사진 위의 작은 서류는 드물다.
2. **판단 결과가 애매할 때만 표시** — p_small 이 0.4~0.6 이면 "검수 필요" 폴더로 보낸다.
   사용자가 전부 확인하지 않고 표시된 것만 보면 된다.

둘 다 새 가짜 샘플로 먼저 확인하고, 그다음 새 실제 서류로 한 번만 확인해야 한다. 이번 실제 서류는 이미 결과를 봤으므로
확인용으로 다시 쓰면 안 된다.

## 3. 다음 단계 — 개인정보 마스킹 (실제 업무의 핵심)

이 도구의 결과물은 **블로그 포스팅용 이미지**다. 블로그에 올리려면 고객 정보를 지워야 한다.

- 지울 것: 이름, 생년월일, 학교명, 학교 위치, 학점·점수, 교직원 이름, 여권번호, 서명, 증명사진 등
- 남길 것: 서류 종류와 구조를 보여 주는 말 — "University", "High School", "APOSTILLE", 항목 이름 등

지금은 이 작업을 손으로 한다. 페이지 분류보다 **훨씬 시간이 많이 들고**, 여기서 AI 이득이 크다.

### 구상한 흐름

```
① 글자 읽기 (OCR: EasyOCR / PaddleOCR)   → 글자와 위치(상자)
② 지울 것 고르기 (로컬 LLM: Ollama)        → 이름·학교명·점수인지, 남길 말인지 판단
③ 얼굴 찾기 (얼굴 탐지 모델)               → 여권·신분증 사진
④ 가리기                                   → 고른 상자에 검은 박스
⑤ 사람이 최종 검수                          → 빠진 곳 추가
```

### 성공 기준 (사용자와 합의)

> 가려야 할 개인정보 항목 중 **90% 이상**을 자동으로 가린다. 나머지는 사람이 최종 검수에서 보완한다.

하나라도 놓치면 개인정보가 공개되므로 "자동 완료"가 아니라 **"자동으로 90% + 사람 검수"** 가 목표다.

### 조건

- **모든 처리는 로컬에서.** OCR·LLM·얼굴 탐지 모두 내 PC 에서 돌아가는 모델만 쓴다.
  외부 API 는 학습에 쓰이지 않더라도 고객 개인정보를 해외 서버로 보내는 것이 되어 제외한다.
  비교 실험은 가짜 서류로만 한다.
- **서류 종류를 좁혀서 시작.** 전 세계 양식이 거의 같은 아포스티유 → 학교마다 양식이 다른 졸업·성적증명서 순서.

## 4. 실제 도입까지 필요한 것

| 항목 | 내용 |
|---|---|
| 실행 방법 | 지금은 명령줄. 폴더에 PDF 를 넣고 더블클릭으로 돌리는 배치 파일 정도면 충분하다 |
| 자료 | 여권·신분증이 있는 실제 스캔 PDF 로 추가 확인 |
| 비용 | 없음. 모델·라이브러리 전부 무료, CPU 로 동작 |
| 라이선스 | PyMuPDF 는 AGPL. 개인 업무용은 문제없고, 남에게 배포하는 제품으로 만들 때만 상용 라이선스 필요 |
